# Minimal personal website

This version intentionally uses a very simple two-column layout:

- Left: one profile photo
- Right: text only

## Replace the photo

Put your photo in:

`assets/profile.jpg`

## Add your CV

Put your resume in:

`assets/Xinyi_Yang_Resume.pdf`

## GitHub Pages

Upload `index.html`, `style.css`, and the `assets` folder directly to the root of your `Euphoria0125.github.io` repository.
