# Xinyi Yang Academic Homepage

This is the filled version of the minimal academic homepage.

## Before publishing

1. Put your portrait photo at:
   `assets/profile.jpg`

2. Put your CV at:
   `assets/Xinyi_Yang_CV.pdf`

3. Upload these items directly to the ROOT of your GitHub Pages repository:
   - index.html
   - style.css
   - assets/

Do not upload the outer folder itself.

## Main sections included

- Bio
- Research Interests
- Research
- Experience
- Education

The text is intentionally limited to material that supports the current NLP / LLM /
multimodal / agent research direction.
