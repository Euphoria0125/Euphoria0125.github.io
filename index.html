Research

Multimodal LLM Agent with Tool Use

Intelligent Perception and Auto-Driving Lab, HUST

I worked on developing a tool-augmented multimodal LLM by extending Monkey/Qwen-VL with external tools for perception, planning, and decision-making. I built a GPT-4-based pipeline for generating tool-calling instruction data and fine-tuned Qwen-VL with LoRA to enable external tool invocation.

The system integrated Grounding DINO, SAM, and InstructPix2Pix into an end-to-end multimodal agent. I also contributed to model evaluation and analysis. The resulting system achieved 45.4 on MM-VET, outperforming the LLaVA-Plus baseline by 29.7%.
